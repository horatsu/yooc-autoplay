Tampermonkey UserScript

易班优课 · 课群课程自动连播

按目录顺序自动完整播放，一节播完自动进入下一节，本页目录全部播完即停止。

它到底做了什么

  • 进入课群课程的学习页后，自动接管播放：点播放、保持播放、检测播放结束。
  • 一节播完，自动在左侧目录里点下一节，然后继续。
  • 目录里所有节都播完，自动停止，右下角弹出「本页课程目录已全部播放完成」。
  • 遇到图文 / 测验这类没有视频的节，等 15 秒后自动跳过，不会卡死。
  • 页面跳转或无刷新切节后，脚本会自己接着跑，不用重新点。

它不做什么 —— 这部分比上面重要

三件事明确不做

不改 currentTime 不拖进度条、不跳到结尾。视频是按真实时长一秒一秒播完的。
不伪造上报请求 不动 saved_video_position / done 这类 AJAX，进度由播放器自己上报。
不处理防挂机弹窗 如果中途弹出确认框，脚本会停下等你处理，而不是自动点掉。

原因很实际：优课后台记录的是每节课的播放时长和进度，你的老师/辅导员能直接看到。那些号称"一秒刷完"的脚本，本质是绕过播放器直接往接口灌一条 done: true，后台一看时长 0 秒却显示完成，就是异常数据。真被抽查到，这门成绩按无效处理，还得重新看。

这个脚本走的是另一条路：机器帮你点，人没看的那部分也只能靠时间换。所以它是"省手"，不是"省时间"。想快只能加倍速，代价见下面。

安装

1
装 TampermonkeyChrome 应用商店 / Edge 加载项 / Firefox 附加组件，搜 "Tampermonkey" 装官方那个（作者 Jan Biniok）。
2
导入脚本两种方式任选：把 yooc-autoplay.user.js 直接拖进浏览器窗口，Tampermonkey 会自动弹出安装页；或者点扩展图标 → 添加新脚本 → 全选删掉编辑器里的模板 → 粘贴全文 → Ctrl+S 保存。
3
确认启用扩展图标上如果有个红色数字 1，说明脚本已装但没开权限，点一下允许即可。已启用状态下图标无提示。

使用

1
进到学习页易班优课 → 我的课群 → 课群课程 → 学习课程。也就是左侧有章节目录、右侧是播放器的那个页面。
2
点右下角「开始连播」面板出现在右下角。点一下，圆点变绿，就开始了。之后可以最小化浏览器，但不要关标签页、不要让电脑休眠。
3
等它跑完面板会实时显示「第 3 / 12 节 · 46% · 12:30 / 27:04」。全部结束会弹提示并自动关掉自己。

面板说明

元素含义
左上圆点灰 = 待机；绿 = 运行中
状态行第几节 / 共几节 · 当前视频百分比 · 已播 / 总时长
进度条对应当前这一节的播放进度，不是整门课的
开始 / 暂停连播总开关。暂停后不再自动切节，也不再强制恢复播放
跳过本节这一节不想等，直接点下一个
倍速1.0 / 1.25 / 1.5 / 2.0
点标题栏折叠 / 展开面板

关于倍速

倍速会真实改变视频的实际播放时长。如果某个课群是按"有效学习时长 ≥ 视频总时长 × 某个比例"来判定的，2 倍速播完只有一半的真实时间，可能判不达标。默认给的是 1.0 倍，不确定的课就别调。

出问题了怎么查

按 F12 打开控制台，看以 [优课连播] 开头的日志。脚本的关键动作都会打点。

现象可能原因怎么办
右下角没有面板 不在匹配的域名下，或脚本没启用 确认地址是 *.yooc.me
日志打印「未识别到课程目录」 这版页面的目录结构和脚本内置的几种选择器都不匹配 把控制台日志和目录区 DOM 截图发我，我加一条规则
一直卡在同一节，不切下一节 视频的 ended 不触发，或时长读取异常 看控制台有没有「本节播放完成」；没有就是没判定到结束
反复从第 1 节开始 目录匹配没命中当前节，退化成从头开始 宁可重播不漏播，属预期兜底；也可以手动点「跳过本节」
视频不自动播 浏览器自动播放策略拦截 脚本会降级为静音播放；还不行就手动点一次播放键
卡在某一节不动 该节是图文 / 测验，或有确认弹窗 等 15 秒会自动跳；或手动点「跳过本节」
切节时页面没反应 目录项绑的是 JS 事件而非普通链接 脚本会在 7 秒后自动重试一次

想改参数

打开脚本，最上面有个 CFG 对象，常用几个：

var CFG = {
  rate: 1,              // 默认倍速
  endSlack: 0.6,        // 距结尾多少秒算播完
  noVideoWaitMs: 15000, // 无视频课件等多久后跳过
  nextDelayMs: 1500,    // 播完后延迟多久切下一节
  handoffMs: 7000,      // 切节后的冷却，防连点
  debug: true           // 装好后建议改成 false，控制台就干净了
};

几点实话

  • 脚本只在你本机浏览器里跑，不发任何数据出去，没有统计、没有回传。代码就那一个文件，可以自己从头读一遍。
  • 平台改版就会失效。页面 DOM 一变，目录识别大概率挂掉，属正常损耗，不是脚本坏了。
  • 先拿一门不重要的课试跑两节，确认切节正常、后台进度确实在涨，再拿去跑正式课。
  • 跑完之后建议回课群首页点一下「显示进度」，确认平台那边记的是 100%，别只信脚本面板。
